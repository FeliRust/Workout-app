MuscleTrack PWA

Para instalar no Android: publique TODOS os arquivos desta pasta num site HTTPS (ex.: GitHub Pages). Abra o endereço no Chrome, menu ⋮ > Adicionar à tela inicial > Instalar. Depois encontre MuscleTrack no Niagara Launcher.

Abrir index.html diretamente como arquivo permite uso básico, mas NÃO habilita a instalação PWA nem garante armazenamento persistente.

Dados: ficam no navegador local. Abas no mesmo navegador e endereço sincronizam via armazenamento local. Navegadores/dispositivos diferentes NÃO sincronizam automaticamente. Use Dados > Exportar backup e Importar backup para transferir manualmente. Para sincronização automática é preciso configurar backend e autenticação (ex.: Supabase).

Antes de migrar do HTML antigo, exporte backup do app antigo e importe no novo.
